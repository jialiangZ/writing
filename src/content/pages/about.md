这里是 [Jialiang Zhang](https://jialiangz.github.io/) 的写作站。香港大学计算与数据科学方向的博士生，研究方向是 AI4Earth 与多模态大模型，具体在做海冰预测和流式视频理解与推理。

站内文章分两种：**长文**是成篇的思考，**短笔记**是随手记下的片段。中文和英文混排，每篇文章在 frontmatter 里声明自己的 `lang`，页面语言、日期格式和界面文案都跟着文章走。

内容全部是 Markdown，放在 Git 仓库里，用 Astro 构建，由 GitHub Actions 发布到 GitHub Pages。没有数据库，没有追踪，也没有任何锁定——哪天想换平台，把 Markdown 拿走就行。

源码：[github.com/jialiangZ/writing](https://github.com/jialiangZ/writing)
